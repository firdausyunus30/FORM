# Azys Flora — Borang Tempahan

Borang statik yang responsif untuk diisi melalui telefon dan dicetak sebagai A4.

## Cara guna

Buka `index.html` dalam browser. Isi butiran tempahan, kemudian tekan **Cetak A4** untuk mencetak atau simpan sebagai PDF.

## Deploy ke Vercel

Import folder ini sebagai projek baharu di Vercel. Tiada build command atau framework diperlukan.

## Deploy ke GitHub Pages

Muat naik semua fail ke repository GitHub, kemudian pilih **Settings → Pages → Deploy from a branch** dan pilih branch utama dengan folder `/ (root)`.
